This blog is built by `braggarr` from markdown files in a repository.

## How a post is laid out

Each post is a folder with an `index.md`. Files beside it are published next to it, and the
[about page](/about/) is a page, not a post.

```sh
braggarr blog new "My next post"
braggarr blog serve
```
